# Hydrogen Production Plant Monitoring and Efficient Management System

A MERN-based web application for monitoring and managing key parameters of a hydrogen production plant.

## 📌 Project Overview

The Hydrogen Production Plant Monitoring and Efficient Management System provides a centralized dashboard for monitoring important plant parameters such as hydrogen production, power consumption, water usage, system efficiency, electrolyzer status, and overall plant status.

The system stores plant monitoring data in MongoDB and displays the information through an interactive React dashboard.

## 🚀 Features

- Real-time plant monitoring dashboard
- Hydrogen production monitoring
- Production target monitoring
- Power consumption monitoring
- Water usage monitoring
- System efficiency monitoring
- Electrolyzer status monitoring
- Overall plant status monitoring
- Plant alerts
- Historical plant data
- Period-based data filtering
- Interactive production charts
- Add new plant monitoring data
- MongoDB data storage
- Backend REST API
- Responsive dashboard interface
